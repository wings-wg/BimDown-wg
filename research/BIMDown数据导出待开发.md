# BIMDown 数据导出待开发清单

目标是让面积测算、模型核查和问答按明确的工程口径读取同一份模型证据，并能追溯每条数据的来源。

2026-11-25 的离线核查显示，现有 `dgsh` 导出可读取楼层标高、房间和楼板对象，但缺少 JT-01、JT-02、JT-03 和 JG-03 所需的适用性或量测证据。JT-08 和 JT-12 分别需要补空间轮廓与门用途、量测等证据。见[验证记录](STATUS.md#网页跨入口-pal-与开发任务交接)。

P0 可在现有本机环境用既有 BIMDown 导出及合成模型开展。P1 按证据契约扩展导出。P2 需要受支持的 Windows/Revit 环境验证。

本轮进展见 [PAL 离线回放](benchmarks/pal-offline.md)。D-04 至 D-07 的离线证据字段与合成验收已接入，真实 BIMDown 导出器实现和 Revit 集成验证仍待开展。

## P0 本地可开展

- [x] **D-01 工程证据契约与兼容校验。** 沿用 `project_metadata.json` 和 `engineering_evidence.json` 的版本约定，校验楼层目录、表、对象 ID、单位、量测口径、来源和确认状态。量测和逐规则适用性分别管理，区分直接量测、确定性派生和人工确认。

  **验收**　旧目录和压缩包仍可读取。异层同短 ID 可各自绑定。记录重复、单位不符、未确认或版本不匹配时，核查说明具体缺口。涉及面积的新增证据另行定义量纲和版本兼容，沿用现有长度证据校验。
- [x] **D-02 JT-01 楼层用途与建筑标高。** 定义住宅楼层、屋面等标高点的用途、建筑完成面标高口径、上方标高对应关系及手工复核来源。沿用 `global/level.csv` 与项目单位，保留模型读出的配对候选和用户确认依据。

  **验收**　标高差可自动预填，可用人工依据修正。最高标高、标高重复或用途不明时保留待确认。结构标高的解释和确认单独记录。
- [x] **D-03 可公开的对照导出样例。** 为同一合成模型准备基础导出、补充证据、口径冲突、版本过期和异层同 ID 样例。

  **验收**　固定规则与工具，记录补数前后的正确执行、证据追溯和拒绝原因。核查记录能关联规则、对象及模型版本。

## P1 专项数据表达与导出

- [ ] **D-04 JT-02、JT-03 房间净高证据。** 在 `<楼层>/space.csv`、`space.geojson` 和相应量测或分析记录中关联房间用途、使用面积边界、完成面最低净高、低于指定高度的面积及对应限值。保留降板、梁、吊顶、包封等限制面的依据。

  **验收**　JT-02 的使用面积和低净高面积用同一边界。每条低净高面积记录保留计算高度。JT-03 可按房间直接读取有来源的完成面最低净高。
- [ ] **D-05 JG-03 楼板结构层厚度。** 对 `<楼层>/structure_slab.csv` 的对象补充板型、是否现浇实心、悬挑状态和有效结构层厚度。允许直接量测，或记录同测点与高程基准的结构层顶底高程。

  **验收**　同一对象的量测与适用性可追溯。名义厚度、结构层厚度和面层厚度分别表达。悬挑、空心、叠合等另判对象可辨识。
- [ ] **D-06 JT-08 与面积测算的空间轮廓。** 建立房间用途、有效闭合多边形及洞口的导出契约，记录上下层配对和共同平面坐标基准。为分摊保留房间归属、共有关系、计入系数及来源，经确认的分摊配置继续由项目侧管理。

  **验收**　同一房间的属性和轮廓可唯一绑定。跨层叠合可复算并回到原始轮廓。面积样例覆盖洞口和分摊守恒。
- [ ] **D-07 JT-12 门用途与有效通行净宽。** 在 `<楼层>/door.csv` 关联户门、居室门、厨房门、卫生间门或待确认用途。保存测线、门扇开启角、门框及五金侵入、量测来源和有效通行净宽。

  **验收**　门用途和已确认净宽可独立核对。洞口宽度或名义门宽保留原有字段及含义。

## P2 Revit 环境验证

- [ ] **D-08 导出器实现与真实模型复核。** 在 Windows/Revit 环境完成导出器编译和集成验证。按 D-02、D-04 至 D-07 对照模型、剖面或已确认的分析记录，记录各字段的来源、可自动提取范围及缺失原因。

  **验收**　真实目录和压缩包可读，同一对象可定位并复算，例外和缺失数据可追踪。

## 上海房产面积测算专项

开发基线采用用户提供的《上海市房产面积测算规范2022》附件，对照沪房市场〔2022〕49号通知记录 2022 年 7 月 1 日施行及过渡规则。逐条对照上次使用的 2017 版附件正文，确认 1.2.1 更正面积单位文字、3.4.23 新增多宗地地下空间规则。两个附件提取的 56 张图像逐像素一致，包括 1.2.3 的限差公式。首期按 2022 版安排单幢住宅离线回放，前期测算、预测、登记及改扩建分别按通知确定适用依据。 [2022 年发布通知及过渡条款](https://fgj.sh.gov.cn/fdcsc/20220620/625681b8a2994896b81de1da99f9b09f.html) · [2017 年发布通知](https://zjw.sh.gov.cn/fwgl/20180912/0011-27478.html)

### 首期 本地证据表达与对照样例

- [ ] **D-09 项目、测量和规则来源。** 记录地上或地下宗地、幢、门栋、自然层及权属单元的稳定 ID。绑定模型版本、业务类型、原测算或预测时间、登记成果或批准依据、适用规则版本及复核记录。改扩建分别关联既有成果、改扩建范围及需重新摊算的范围。边长保留原测值、水平测值、量测来源和 0.01 m 的取值记录。面积单位与取值为 m² 和 0.01 m²，并保留计算原值。依据通知第二至第六项及附件 1.1、1.2、3.4.1 和 3.4.21。

  **验收**　同一个 BIMDown 数据包可按原成果与 2022 规则独立回放。切换依据时可追溯到成果或范围及其版本。缺少预测、登记或测量依据时报告具体缺口。
- [ ] **D-10 房屋外围、套界和共有边界。** 沿用 BIMDown 构件和 GeoJSON。分别记录建筑外围、结构中心线、内侧面、贴附面层、墙体两侧归属及共有外半墙，另存套界、专有阳台和洞口。保留每段线或面的来源构件、楼层、坐标基准、边界类型及确认状态。粉刷、黏贴饰面或保温与干挂装饰分别表达。依据附件 2.1.3、2.2.23（2）、2.3.1、3.3.1、3.3.2 和 3.4.19。

  **验收**　同一案例可分别重建幢外围、套界和共有部位边界。中心线围成面积与分项拆计在同一测量口径下可核对，公共墙及外半墙有重复计量检查。房间种子点和已有模型净面积仍可作为取数线索。
- [ ] **D-11 共有部位与受益范围。** 单列专有、可分摊共有、计入建筑面积但不分摊的部位以及独立使用空间，记录全幢、功能区间、功能区、部分层、层内和局部的受益范围、接收单元及权属或协议来源。保留独立核定的幢面积供校核。依据附件 3.1 至 3.4。

  **验收**　能表达单幢住宅、不同楼层服务范围、独立使用空间和协议分摊。按门归户得到的结果供审核，服务范围和权属依据可单独核对。计入资格和参与分摊资格可各自追溯。
- [ ] **D-12 建立离线验收样例。** 用同一合成模型提供基础证据、补证据、口径冲突和版本不符的数据包。首批覆盖套内墙体、阳台和单幢共有面积，增加历史预测转实测、改扩建复算，以及第 1.2 节的两种取值单位与面积尾差样例。用手工审定的图形和算式建立参考答案。

  **验收**　现有本机可用目录或压缩包复算。位于不同楼层的同短 ID 能独立绑定，缺少证据的部位有可执行的补数建议。现有 `project-config.json` 项目可按原口径重跑。

### 第二期 复杂部位与真实导出

- [ ] **D-13 补充形态与跨层证据。** 按附件 2.2、2.3 提供上盖、前后及侧护栏、底板和柱墙轮廓，上盖前沿遮蔽关系、结构面高度和自然层间隔。补充幕墙与主墙标识、飘窗窗台高差、跨层空间与上空、井道及楼梯自然层关系。斜弧结构需有达到对应高度的截线或可验证的几何来源。

  **验收**　可重建图 2.2.12 的全遮挡、侧向部分遮挡与前沿未遮挡。相同外轮廓但结构面高度、盖板或层数不同的部位保留不同证据。建筑层高、面积测算结构高度和完成面净高字段各有独立口径。
- [ ] **D-14 补地下、车库和幢间对象。** 按附件 3.4.5 至 3.4.11、3.4.16 至 3.4.22 记录地上地下宗地及幢的界定依据、地下竖向交通、车位类型和占用范围、套内停车间及幢间连接的服务范围。分开表达同宗地幢间共用、地上地下分宗地及第 3.4.23 条的多宗地地下整体开发。

  **验收**　共享地下室、地下车库及同宗地连接案例可独立核对参加和排除对象。具备 Windows/Revit 环境后再验证导出器读取的结构几何与原图一致。本机先用合成包和有来源的人工录入验证。
- [ ] **D-15 多宗地地下空间的界线、权属及服务证据。** 按附件 3.4.23 接入经核定的宗地界线及共同坐标基准、地下楼层和空间范围。支持把跨界空间的各片段关联到同一原始空间和各自宗地。记录宗地间权属备注、共用通行部位的归属、设备及管理用房的服务宗地清单及其文件依据。导出的几何与权属或服务范围分别确认。

  **验收**　两个相邻地下宗地的合成包能表达跨界空间、各宗地内共用通道和服务多宗地的设备或管理用房。片段可追溯到原空间，重叠、缺口、坐标不一致或服务范围未知可定位。先用带来源的宗地文件和人工录入复验，再扩展实际导出器。
