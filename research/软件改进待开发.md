# 软件改进待开发清单

目标是把面积测算与分摊、模型核查和自然语言问答中的反馈，转成可追踪、可验收的改进任务。已有功能建议表单、任务 JSON 和本机 coding agent 交接脚本，待补齐实际执行、回执和跨版本复验。

2026-11-25 的离线核查生成了本地报告和工具库。新工具库实例可读到三项配方，当时运行的 5174 服务仍返回已缓存的空库。原工作簿 97 条中 4 条进入执行器并产生 102 条无法判断记录，其余 93 条保留待处理原因。见[验证记录](STATUS.md#网页跨入口-pal-与开发任务交接)。

## P0 本机工作流

- [x] **S-01 增加删除的交互操作。** 在下方工具条中增加删除按钮，对用户选中的对象进行删除。将该命令加入命令列表中，用户在问答窗口中可用自然语言要求删除某个、某类对象。

  **验收**　合成模型验证选中构件删除与撤销、问答确认和取消。跨楼层的同短 ID 不会映射到当前楼层。
- [x] **S-02 接入 Codex 生成的候选与工具库刷新。** 为模型核查页提供本地导入入口，校验候选包、原文绑定、配方和验证记录。导入后刷新同一服务的工具库状态，区分候选、启用和验证失败。

  **验收**　已打开的项目页可导入候选并看到工具库更新。模型、条款审核草稿和既有报告在导入过程中可保留。重复提交不会产生重复工具，候选仍走审核流程。依赖 T-01，接口与 T-06 协同。
- [ ] **S-03 核查结果按条款和对象复核。** 同时展示原表总条款、已编译、待审核、已执行和待处理数量。对象结果按通过、不通过、不适用和无法判断筛选，支持跳到模型中的具体作用域对象。

  **验收**　跑完整份 97 条工作簿时，每条均能追溯至工作表位置、方案和状态。结果页可定位已识别对象，下载报告能复查对象证据、工具版本及筛选所依据的状态。
  **进展**　已实现。浏览器与执行器使用 97 条合成工作簿验证，原始工作簿尚待本轮复验。
- [x] **S-04 导出建议、补证据和复跑。** 将缺证据提示关联到条款、作用域对象、建议文件、字段和口径，支持保存后补数据并对受影响条款重新诊断。

  **验收**　用户可从 JT-01、JT-02、JT-03 和 JG-03 的缺口回到模型对象或对应模型文件。证据更新后可比较两次结果，报告标明各自模型版本。依赖 D-01 至 D-05。

## P1 跨入口体验与开发交接

- [ ] **S-04 统一三个入口的计划和审核体验。** 面积测算、核查和问答显示各自计划的作用域、证据、适用条件和审核状态。完善从问答到模型核查的条款转送、面积方案复核和附证据的问答。

  **验收**　可从问答将条款原文送到核查，从同一构件定位回模型。面积测算使用已确认的边界、系数及分摊关系。核查和问答可调用同一启用工具并追溯版本。
- [ ] **S-05 完成一项真实 coding agent 交接。** 复用「功能建议」表单和开发任务 JSON，选取一个范围明确的实际交互问题，记录当前行为、复现步骤、预期行为、验收标准和基线版本。在显式发起的独立工作目录实施。

  **验收**　任务可追踪到代码差异、完成状态、验收和回归结果，经审核后纳入版本。网页可交付和查看任务，仓库操作由开发者发起。

## P2 用反馈检验版本演进

- [ ] **S-06 建立跨版本回放与变更记录。** 关联运行中发现的问题、数据补导、工具启用或代码改动，保留变更前后的版本、验收和复验结果。

  **验收**　至少分别复验数据补充、工具复用和程序改进的案例。每轮保留历史回归任务及预留的未见任务，记录正确执行率、错误放行、重复缺口、既有功能回归与人工投入。

## 上海房产面积测算专项

以现有面积测算侧栏、房间归户和分摊配置为入口，采用 2022 版开发基线。工作流程按「确认测算依据及范围 → 复核边界与计入 → 确认权属及受益关系 → 计算与校核 → 导出成果及复算依据」组织。首期在本机完成合成单幢住宅与过渡项目的复算，第二期增加复杂项目及第 3.4.23 条的多宗地地下空间流程。参考版本和过渡条款见[数据专项](BIMDown数据导出待开发.md#上海房产面积测算专项)。

### 首期 单幢住宅工作流

已实现 S-07 至 S-10 的单幢住宅复算入口。可读取、导入或编辑复核证据，确认房产测算范围和来源后查看分户与分项，下载证据和离线复算报告。边界图层、原构件定位和可视化范围编辑仍待开发。 [网页操作说明](../web/area/README.md#上海-2022-版单幢房产面积)

- [ ] **S-07 项目和规则版本。** 增加宗地、幢、门栋和测算范围，以及新测算、纠错、已有预测转实测、登记后分割或合并、改扩建等业务类型。录入原成果和业务依据，显示推荐的适用规则及原因并由用户确认。改扩建分别呈现既有成果、改扩建范围和按 2022 版重新摊算的任务。依赖 D-09、T-08。

  **验收**　导入旧项目后可复算原配置，并在独立任务中预览 2022 版结果。过渡任务能确认原规范依据和适用范围，缺少证明时显示待确认，原成果保留可查。
- [ ] **S-08 模型上的测算边界审核。** 在平面图分别叠加建筑外围、墙体结构中心线、套界、共有范围、洞口和阳台参与测算的投影。支持选取、修改、人工补证并定位原构件。显示原轮廓、计入范围和系数，并区分已计入、已确认不计入和待核定。按门归户继续提供候选，用户确认其用途和归属。依赖 D-10、T-09。

  **验收**　可从面积分项定位至原构件并查看来源和对应条款或图例。修改边界后标明受影响的分项和上次结果。手工修正记录修改前后值、原因和确认依据。
- [ ] **S-09 共有部位与受益对象审核。** 增加专有、共有、计入但不分摊及独立空间的清单，复用现有共用房间编辑能力。按幢及后续分级关系编辑服务范围、接收单元、扣除项和约定来源，并预览受影响的户。依赖 D-11、T-10。

  **验收**　在同一项目中可区分应计入建筑面积的独立空间和各套实际参与分摊的共有池。首期复核单幢的幢总面积、套内合计、扣除项、可分摊差额和分母。存在遗漏、重复或未审核范围时指向相关分项。
- [ ] **S-10 分户报告和离线复算。** 输出幢总面积、套内使用/墙体/阳台明细、共有面积和扣除明细、分摊系数及各套面积。边长展示 0.01 m 的采用值，面积展示 0.01 m² 的取位结果，计算原值、四舍五入尾差、守恒检查和经审核的限差比较可分项查看。保存模型、证据、规则、工具及审核版本，提供可阅明细和机器可读的复算记录。依赖 D-12、T-10、T-14。

  **验收**　单幢手算样例的结果与 CLI、网页报告一致。报告能从套建筑面积追溯到每条边界、分项和分摊来源。未确认的必要数据在草稿中明确显示，审核后的成果可在离线环境复算。

### 第二期 复杂项目与改进反馈

上海 2022 页面可按标高层查看候选投影、定位板和洞口、查看房间补数项并下载模型候选证据。已用真实导出验证二层构件定位，推进 S-08 和 S-12 的证据复核和反馈。 [操作说明](../web/area/README.md#上海-2022-版单幢房产面积)

- [ ] **S-11 专项审核和分级分摊界面。** 增加自然层去重、特殊部位和覆盖范围的复核视图。显示各级分摊的实际分母、受益对象、流向、互相跨越的服务范围及系数乘积。地下及车位明细单列，提供幢间例外和协议的依据入口。依赖 D-13、D-14 和 T-11 至 T-13。

  **验收**　有地下空间、门栋及混合用途的案例可分别复核。修改服务范围后可对照受影响的单元及旧版报告。未经确认的幢间例外保留待审。
- [ ] **S-12 反馈回路与验收。** 同一问题记录触发项目、对象、条文、证据和前后版本。缺数据生成 BIMDown 补导建议，缺算法转成 PAL 工具任务，软件或交互问题输出带复现与验收标准的 coding agent 开发任务。复用三类反馈的既有接口。

  **验收**　增加证据、启用工具和更新程序分别跑一个回归案例。新旧模型、规则或工具版本可独立回放，能区分新覆盖的任务和历史结果的变化。
- [ ] **S-13 多宗地地下空间审核与成果。** 按 2022 版 3.4.23 叠加经核定的宗地界线、地下空间及跨界切分片段。支持复核宗地间的权属备注、通行部位归属以及多宗地服务关系。结果按宗地列出计量、共用通行分摊和不分摊明细，可从明细回到原构件及文件。依赖 D-15、T-15。

  **验收**　两宗地合成算例能分别查看、审核和导出各自面积。跨界通廊的片段各自进入对应宗地，设备及管理用房的不分摊项可追溯到已确认的服务关系。变更界线或服务关系后定位受影响的宗地和上次结果，缺证据的分项保持待核定。

证据缺口转入 [BIMDown 数据导出待开发](BIMDown数据导出待开发.md)，算法或规则结构缺口转入 [PAL 工具库待开发](PAL工具库待开发.md)。工作包和实验口径见[开发路线图](ROADMAP.md)。
