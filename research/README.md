# PAL辅助的BIM工程要求语义落地与可验证计算

## 目标

研究如何将自然语言工程要求转换为具有明确数据前提、可执行计算和可追溯证据的分析过程。BIMDown提供模型数据载体；PAL辅助规则理解与工具规划；确定性算法负责计算，专业审核负责关键口径确认。

三个候选核心贡献：工程要求的可计算语义表示；基于语义与数据契约的可计算性诊断；具有计算验证和证据追溯的LLM—程序协同执行。新颖性需经文献综述和实验确认。

## 按核心贡献组织项目

| 核心模块 | 主要任务 | 产出 |
|---|---|---|
| C1 可计算语义表示 | 工程概念、PAL转换、规则校验与审核 | 有来源和口径的Rule |
| C2 可计算性诊断 | 数据/工具契约、概念绑定、依赖分析 | 放行条件或明确缺口 |
| C3 可验证协同执行 | PAL工具计划、受控执行、验证与证据 | 可复算结果与证据图 |

BIMDown适配和算法库为支撑层；基准与实验为评价层。面积分摊和模型核查为应用案例。实施按P0基线、P1语义、P2诊断、P3执行、P4迁移、P5评价推进；完整接口和验收见下列文档。此划分是开发与研究计划，不表示三个核心模块已经实现。

## 示例

安装依赖并在仓库根目录构建后：

```bash
npm install
npm run build --workspace=cli
node cli/dist/cli.js area-project sample_data/area-example/model -c sample_data/area-example/project-config.json -o /tmp/bimdown-area-report.json
```

示例预期：套内80平方米，分摊20平方米，合计100平方米。它验证显式确认输入下的计算链路，不证明自动识别了分户、权属或法定测算边界。命令的完整构建/运行状态见STATUS。

## 范围

面积分摊和住宅模型核查为主案例；后续用工程量提取或变更影响分析验证迁移能力。首版要求人工确认关键语义与项目条件，不追求无配置产权识别、自动法规认证或任意代码执行。

用户提供的面积PDF及核查Excel为需求材料，未作为公开研究数据集纳入仓库，阈值及条文效力尚未独立核实。后续需建立具有来源和适用版本的规则集及可发布合成案例。
