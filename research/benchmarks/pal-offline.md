# BIMDown 与 PAL 离线回放

同一份合成 BIMDown 模型、规则和工具用于对照。算例覆盖 JT-01、JT-02、JT-03、JG-03 的基本厚度限值、JT-08 和 JT-12。各条款限值来自算例中的规则文字，真实项目仍需审核规则和证据的适用性。

| 算例 | 数据差异 | 核查预期 |
|---|---|---|
| 基础导出 | 已有模型对象及轮廓，工程证据文件缺失，楼层配对待确认 | 30 个对象结果均无法判断 |
| 补证据导出 | 同一模型增加版本匹配、带来源的量测及适用性，确认适用的楼层配对 | 12 个通过、6 个不通过、10 个不适用、2 个无法判断 |
| 口径冲突 | 用名义板厚概念代替有效结构层厚度 | 两个原可判断楼板分别退回无法判断，已排除楼板维持不适用 |
| 过期证据 | 工程证据对应旧模型版本，楼层配对待确认 | 30 个对象结果均无法判断，反馈版本冲突 |

两个有意保留的缺口是最高标高点的适用性和一樘门的未确认用途。补证据算例中，800 mm 有效净宽的户门和居室门采用各自限值，结果分别为不通过、通过。跨层叠合覆盖正面积相交、完全位于下层轮廓洞内、仅边界相接及完全分离。其他检验覆盖异层同短 ID、重复或未确认记录、坐标基准不匹配、缺上下层配对以及规则未审核。

## 复现

在仓库根目录执行。启动准备见[网页使用说明](../../web/area/README.md)。

```sh
node web/area/setup.mjs
cd .bimeditor-local
npm exec -- vitest run app/src/check/pal-offline.test.ts app/src/check/storey-height.test.ts
```

合成文件由 [fixtures](../../web/check/pal-offline-fixture.ts) 构造，测试调用网页采用的同一规则校验和模型核查执行器。工程证据新增字段见[格式定义](../../spec/engineering_evidence.schema.yaml)，楼层标高口径见[楼层表定义](../../spec/csv-schema/level.yaml)。
