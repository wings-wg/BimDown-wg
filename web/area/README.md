# BimEditor 面积测算与分摊

面积侧栏运行在本地 BimEditor 实例中。用户从二维模型选取房间，也可以导入原有的 `project-config.json`。计算在浏览器中复用 CLI 的 [模型证据绑定](../../cli/src/area/project-input.ts) 和 [面积算法](../../cli/src/area/index.ts)。原版编辑器的模型打开、二维和三维功能由上游提供。

## 启动

在 BimDown 仓库根目录执行。已有 `.bimeditor-local` 时跳过克隆与切换版本。使用 Node.js 24 运行。

```powershell
git clone https://github.com/NovaShang/BimEditor.git .bimeditor-local
git -C .bimeditor-local checkout --detach f0c2e2386bce098484026ac093c3f30f7b95b3b3
npm --prefix .bimeditor-local install
node web/area/setup.mjs
npm --prefix .bimeditor-local run dev --workspace=app
```

用 Chrome 或 Edge 打开终端提示的本地地址，默认是 `http://localhost:5174`。更新面积侧栏或共享算法后，再运行一次 `node web/area/setup.mjs`。该命令将跟踪的集成源码复制到忽略的本地上游检出目录。生产构建使用 `npm --prefix .bimeditor-local run build --workspace=app`。

开发服务器检测到共享编辑器源码变更时会刷新整页。刷新后，从首页重新打开项目。更新前可将内存中的 ZIP 项目下载或保存到文件夹，以保留会话内的编辑。打开本地目录时，选择包含 `global/level.csv` 的项目根目录，页面会显示楼层读取状态。

## 使用

1. 在首页打开本地项目目录、Revit 导出的 `.bimdown` 包或 `.zip` 包。先试运行时，可使用首页的样例入口。
2. 打开右上角的 **面积测算与分摊**。样例点 **读取项目配置**，实际项目可以导入配置，或在二维图中选择一个房间并填写建筑 ID、归属、计入系数和边界依据，再点 **加入所选房间**。
3. 为共有池设置接收节点和分摊方法。等份与自身计入面积比例可在表单录入。显式权重、补充测量分项、多种计入部位、自动系数条件与独立幢总量可在 **配置 JSON** 中维护。
4. 核对规则来源、轮廓边界、归属和分摊范围，勾选审核确认并运行测算。样例应显示套内 80 m²、分摊 20 m²、合计 100 m²。点击结果中的模型分项可定位房间。下载的配置与报告使用 CLI 格式。

测算支持现有 `area-project` 契约中的 BIMDown GeoJSON v2 及其单位。几何文件、测算配置与报告保留在本地浏览器或用户选择的本地位置。实际项目的边界、共有归属和计入系数仍由审核人确认。

## 按入户门归户

1. 在当前楼层的二维平面上选中一樘入户门，在面积侧栏展开 **按入户门归户**，填写户号，点击 **预览户内房间**。
2. 查看预览中的房间。若门两侧都是候选，先从 **选择户内一侧** 选取起点，再点 **确认批量归户**。已标记的公共房间、已有共有池或排除归属的房间，以及其他标记为户界的门会阻断遍历。若同层两侧可经其他门重新连通，页面会要求先明确户界。跨楼层的连通关系会提示另行核对。
3. 新增分项暂用计入系数 1。房间缺少可测算轮廓时仍可保存归户草稿，测算前须补齐轮廓。例如，可在项目工作副本运行 `bimdown build` 计算基于墙体的 `space.geojson`，然后依据测算要求审核生成的轮廓。

按门归户需要 Revit 导出的 `area_features.json` 和能唯一对应楼层、短 ID、UUID 的 `_IdMap.csv`。旧导出包的跨层短 ID 若有歧义，用新版插件重新导出门和房间。对无法判断户内一侧的模型，可按需在 Revit 中标记公共房间和其他户界门。可选参数见 [Revit 面积证据说明](../../revit-addin/Area/README.md)。

内置面积样例也可试归户：打开样例后保持空白配置，选择公共走廊与客厅之间的门 `d-1`，填写 `101` 并确认。预览应包含客厅和卧室。填写测算规则来源并审核后，示例套内面积为 104 m²。

## 自动创建房间

1. 在 **面积测算与分摊 → 自动创建房间** 选择 **当前楼层** 或 **全部楼层**，点击 **识别闭合房间**。网页使用墙、结构墙、幕墙及房间分隔线识别闭合区域，跳过已有房间占据的区域。
2. 核对预览的定位点和面积，取消勾选管井等不应创建房间的区域，然后点击 **创建所选房间**。编辑器按楼层标高由低到高、同层按平面从上到下再从左到右创建。房间名称如 `F1-room1`、`F1-room2`、`F2-room3`，编号在整个项目中延续。已有房间保留原名。
3. 新建房间按编辑器惯例保存到相应楼层的 `space.csv`，整批可以一次撤销。打开本地文件夹时使用编辑器的自动保存，打开压缩包时可下载编辑后的 ZIP。

预览显示墙面之间的计算面积，无法计算墙面内轮廓的区域标注为墙中心线面积。几何候选可能包含公共区域，测算口径和归属仍需审核。批量创建生成网页的房间种子点，按门归户需要单独提供门—房间连通证据。面积分摊需要审核过的测算轮廓；可在项目工作副本上运行 `bimdown build` 生成 `space.geojson` 后核对。

## 导出模型显示

安装脚本会修正 Windows 检出时的三维 HDR 资源，并让缺少宽度的门窗使用编辑器已有的显示尺寸计算视图范围。显示尺寸仅用于可视化，测算仍使用项目中可复核的几何证据。只有房间种子点时，面积侧栏需要另行提供审核过的多边形轮廓才能从模型测算。
